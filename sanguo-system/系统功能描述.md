# 三国演义智能分析系统 - 功能描述

## 系统概述

《三国演义智能分析系统》是一个基于 Vue3 + TypeScript + Vite 构建的交互式名著学习平台。系统以《三国演义》120回全本原文为基础，通过数据提取、智能分析和可视化技术，将一千多个人物、数十场战役、复杂的势力关系和地理分布以直观的方式呈现给读者，帮助用户快速掌握三国历史脉络，提升阅读效率和学习体验。

**技术栈**：Vue 3 + TypeScript + Vite + Element Plus + Vue Router + Leaflet（地图） + Cytoscape（关系图）

| 数据项 | 数量 | 说明 |

| 人物关系 | 200+ 条 | 结义、君臣、父子、敌对、姻亲等 |

## 八大功能模块

### 一、首页

**入口**：`/`

系统首页提供一站式导航和核心数据概览：

- **英雄区**：大气的三国主题视觉设计，展示"简化阅读 · 高效学习 · 深度解读"的核心理念
- **数据统计**：实时显示人物数、章回数、战役数、势力数等核心指标
- **三国鼎立**：蜀汉、曹魏、东吴三大势力卡片，点击可跳转到对应势力人物列表
- **功能导览**：7大功能模块入口卡片，直观描述各模块特色
- **经典战役**：精选战役快捷入口，支持一键跳转

---

### 二、人物谱

**入口**：`/persons` · 详情页：`/persons/:id`

全本 1085 位三国人物的智能数据库，基于原著原文精准统计。

#### 人物数据字段

| 字段 | 说明 |
|------|------|
| 姓名 / 字 / 号 | 人物基本信息 |
| 生卒年 | 出生与逝世年份 |
| 籍贯 | 人物出生地 |
| 容貌描写 | 原著原文摘录的外貌描述 |
| 兵器 / 坐骑 | 人物装备 |
| 势力归属 | 蜀汉/曹魏/东吴/群雄/其他 |
| 身份角色 | 君主/武将/谋士/文官等 |
| 重要度 | 1-10 星级评价 |
| 出场次数 | 基于原著全本精确统计（含别名） |
| 人物传记 | 核心生平简介 |
| 性格标签 | 人物性格特征关键词 |
| 经典故事 | 该人物相关的经典情节列表 |
| 相关章回 | 人物实际出场的章回（截止到死亡/退场回目） |
| 人物头像 | 国风风格人物画像 |

#### 筛选与排序功能

- **势力筛选**：按蜀汉、曹魏、东吴、群雄等势力过滤
- **分类筛选**：主要人物、重要人物、次要人物、无名角色四级分类
- **关键词搜索**：支持姓名、字、号模糊搜索
- **多维排序**：支持按重要度、出场次数、首出场回目、姓名排序
- **升降序切换**：灵活调整排列顺序
- **分页浏览**：支持大量人物的流畅浏览

#### 人物详情页

- 人物头像与基本信息展示
- 容貌描写（原著原文）
- 人物传记与性格标签
- 经典故事时间线
- 出场统计（次数、首章回、相关章回列表）
- 所属势力标识
- 兵器、坐骑等特色信息

### 三、原文阅读

**入口**：`/reading`

120 回全本《三国演义》原文阅读器，仿古书卷排版，沉浸式阅读体验。

#### 核心功能

- **左侧章回目录**：
  - 120回完整目录，点击跳转
  - 支持按卷筛选（全书分卷）
  - 已读回目标记
  - 当前回目高亮

- **阅读工具栏**：
  - 目录显示/隐藏切换
  - 上一回 / 下一回快速翻页
  - 字体大小调节（A- / A+）
  - 字体切换（宋体 / 楷体 / 黑体）
  - 阅读设置本地保存

- **仿古排版**：
  - 章回标题艺术装饰
  - 首段缩进效果
  - 段落分明的正文排版
  - 卷名与字数显示
  - 结尾装饰纹样

### 四、战役志

**入口**：`/battles` · 详情页：`/battles/:id`

28 场经典战役详解，快速掌握三国战争脉络。

#### 战役数据字段

| 字段 | 说明 |
|------|------|
| 战役名称 / 别名 | 战役基本信息 |
| 发生时间 | 历史年代 |
| 所属章回 | 对应原著第几回 |
| 交战双方 | 参战势力 |
| 主要指挥官 | 双方统帅人物 |
| 战役地点 | 古战场名称 |
| 战役结果 | 胜负结局 |
| 历史意义 | 战役影响与地位 |
| 详细描述 | 战役经过与关键情节 |

#### 展示特色

- **卡片式布局**：战役卡片按重要度配色（特级战役红色、重要战役金色）
- **结果标识**：胜/负/相持不同颜色区分
- **详情页**：完整的战役背景、经过、结果和影响分析
- **章回关联**：每场战役对应原著回目，可延伸阅读

#### 涵盖战役（部分）

- 黄巾之乱、讨伐董卓、虎牢关之战
- 官渡之战、赤壁之战、夷陵之战（三大战役）
- 合肥之战、汉中之战、襄樊之战
- 诸葛亮北伐、姜伯约九伐中原
- 魏灭蜀、晋灭吴、三国归晋

### 五、时间轴

**入口**：`/timeline`

三国百年大事年表，一目了然的历史发展脉络。

#### 功能特色

- **左右交替布局**：时间轴居中，事件卡片左右交替排列
- **分类筛选**：政治、军事、人物、外交、其他五大类
- **颜色区分**：不同类型事件使用不同颜色标识
- **事件详情**：每个事件包含年代、标题、描述、对应章回
- **关联原著**：事件标注对应章回，方便回溯原文

#### 事件类型

- **政治事件**：朝代更替、权力斗争、制度变革
- **军事事件**：重大战役、军事行动、战争转折
- **人物事件**：重要人物出生、逝世、关键抉择
- **外交事件**：联盟、联姻、议和、出使

### 六、地理图

**入口**：`/map`

交互式三国地理地图，直观展示疆域分布与战场位置。

#### 三种图层模式

1. **三国总图**：
   - 80+ 处历史地点标注
   - 按类型分类：都城、城池、关隘、州郡、地点
   - 不同颜色图标区分地点类型
   - 点击地点查看详情

2. **势力分布**：
   - 蜀汉、曹魏、东吴三大势力疆域图
   - 疆域多边形半透明填充
   - 不同势力用代表色区分（蜀绿/魏蓝/吴红）
   - 直观展示三国鼎立格局

3. **战场路线**：
   - 经典战役发生地标注
   - 进攻路线可视化
   - 战役地点与路线关联

#### 技术实现

- 基于 Leaflet 地图引擎
- 自定义底图与标注样式
- 支持缩放、拖拽交互
- 图例说明面板

### 七、关系图

**入口**：`/graph`

人物关系网络可视化，直观展现复杂的人物关系网。

#### 核心功能

- **势力筛选**：可选择显示哪些势力的人物
- **关系类型筛选**：结义兄弟、君臣、父子、敌对、姻亲、朋友等
- **节点大小**：根据人物重要度动态调整
- **节点颜色**：按势力归属区分颜色
- **连线颜色**：按关系类型区分颜色

#### 关系类型

| 关系类型 | 说明 | 示例 |
|----------|------|------|
| 结义兄弟 | 桃园结义等 | 刘备-关羽-张飞 |
| 君臣 | 君主与臣属 | 刘备-诸葛亮 |
| 父子 | 血缘父子 | 关羽-关平、关兴 |
| 敌对 | 战场对手 | 诸葛亮-司马懿 |
| 姻亲 | 联姻关系 | 刘备-孙尚香 |
| 朋友 | 知己好友 | 孙策-周瑜 |
| 师徒 | 师承关系 | ... |

#### 交互特性

- 基于 Cytoscape 图形库
- 力导向布局，自动排列
- 支持拖拽节点调整位置
- 缩放与平移浏览
- 点击节点查看详情

## 数据特色与准确性

### 人物数据精确性

1. **出场次数统计**：
   - 基于《三国演义》全本原文逐回统计
   - 考虑人物别名（如关羽统计"关公""云长""关云长""美髯公"等）
   - 示例：诸葛亮 2461次、刘备 2449次、关羽 994次

2. **相关章回校准**：
   - 截止到人物死亡/退场回目
   - 如诸葛亮截止第104回（五丈原归天）
   - 关羽截止第77回（败走麦城）
   - 避免死后仅被提及的回目计入

3. **容貌描写**：
   - 摘录原著原文描述
   - 如诸葛亮"身长八尺，面如冠玉，头戴纶巾，身披鹤氅"
   - 如关羽"身长九尺，髯长二尺，面如重枣，丹凤眼，卧蚕眉"

4. **经典故事**：
   - 从回目标题和情节中提炼
   - 重要人物可达 10-20 个经典故事
   - 按时间顺序排列

### 人物分类体系

| 分类 | 说明 | 数量 |
|------|------|------|
| main（主要人物） | 核心角色，有独立传略 | 45人 |
| supporting（次要人物） | 重要配角，推动剧情 | 78人 |
| minor（小人物） | 一般角色，有姓名 | 618人 |
| unnamed（无名角色） | 无全名，有独立情节 | 344人 |
